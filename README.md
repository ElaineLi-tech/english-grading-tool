# 英语作业自动批改工具

一个带图形界面的本地Web工具，支持一键批改英语作业并生成Word文档。

## 🚀 快速开始

### 方法一：双击启动（推荐）
双击 `start.command` 文件，工具会自动启动并打开浏览器。

### 方法二：命令行启动
```bash
cd grading_tool
python3 app.py
```

然后在浏览器中访问：http://localhost:5000

## ✨ 功能特色

### 📖 中考作文批改
- 按上海中考英语作文评分标准（20分制）
- 三维评分：内容（8分）+ 语言（8分）+ 组织结构（4分）
- 逐句错误批注 + 详细分析 + 改进建议
- 范文参考 + 好词好句学习

### 📚 高考作文批改
- 按上海高考英语指导性作文评分标准（25分制）
- 三维评分：内容（10分）+ 语言（10分）+ 组织结构（5分）
- 错误类型汇总表 + 定档理由
- 原文基础的范文讲解（修改部分标粗）
- 结尾升华指导 + 提升建议

### 📋 概要写作批改
- 要点完整性评分
- 句型转换分析
- 语言准确性评价
- 参考概要 + 解析

### 🌐 翻译批改
- 采点给分制
- 逐句语法/词汇/句式分析
- 参考译文 + 精准解析

## 📁 支持的文件格式

- 🖼️ 图片：PNG、JPG、JPEG
- 📄 PDF文档
- 📝 Word文档：.doc、.docx
- ⌨️ 也可以直接粘贴文本

## 📂 文件结构

```
grading_tool/
├── app.py              # 后端主程序（Flask）
├── start.command       # 启动脚本（双击运行）
├── templates/
│   └── index.html      # 前端界面
├── uploads/            # 上传的文件（自动创建）
└── outputs/            # 生成的批改文档（自动创建）
```

## 💡 使用说明

1. 双击 `start.command` 启动工具
2. 浏览器会自动打开页面（如未自动打开，手动访问 http://localhost:5000）
3. 点击顶部标签选择批改类型（中考作文/高考作文/概要写作/翻译）
4. 粘贴学生作业文本，或上传图片/PDF文件
5. 点击"开始批改"按钮
6. 等待几秒，批改完成后点击下载Word文档

## ⚙️ 系统要求

- macOS / Windows / Linux
- Python 3.7+
- 浏览器（Chrome、Safari、Edge等）

## 📝 注意事项

- 本工具在本地运行，所有数据不会上传到外部服务器
- 首次运行会自动安装所需依赖（Flask、python-docx）
- 批改完成的Word文档保存在 outputs 文件夹中
